# One-Star Review of Something Essential

make.fun bounty entry: one deadpan one-star review, at most 160
characters, of an everyday essential.

## The review

> Gravity: holds the oceans in place, but lets my phone slip off the bed every night.

## Run

```sh
node main.ts
```

Writes the review to `/output/entry.txt`. The program validates the
gate itself before writing: 1–160 characters, not only whitespace,
one line, no exclamation mark.
